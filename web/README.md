# Admin / Demo UI

Веб-интерфейс по спецификации `docs/agents/09-demo-ui.md`: настройки (токен, базовый URL), поиск, база знаний (кейсы), тикеты, приложения.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Укажите Bearer-токен и при необходимости базовый URL API в разделе **Настройки**, нажмите «Сохранить в браузере». Тип доступа (App / Staff) определяется автоматически при первом заходе или после сохранения токена.

## Сборка

```bash
npm run build
```

Артефакты в `web/dist/`. Раздача: любой статический сервер или опционально маршрут в модуле 08 (например `GET /app/*` → `web/dist/`). При раздаче с подпути (например `/app/`) задайте `basename="/app"` для `BrowserRouter` в `src/main.tsx`.
